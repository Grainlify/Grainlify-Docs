# Keeping Your Project in Sync

## Syncing is automatic

Once your project is connected, Grainlify keeps its issues and pull requests
up to date on its own — there's nothing to trigger manually. New issues,
new applications, comments, and merged pull requests reflect on Grainlify
shortly after they happen on GitHub. You don't need to do anything to keep
it current; just work on GitHub as you normally would.

## Editing your project's details

Open your project from the repository picker in the Maintainer view and
select **Edit** to update its description, ecosystem, language, tags, or
category — the same details you filled in during setup. Changes are visible
to contributors as soon as you save.

The connection to your GitHub repository itself is fixed once set up — if
you need to point Grainlify at a different repository, connect it as a new
project.

## Removing a project

Grainlify follows your repository's access, so removing it is done from
GitHub, not from Grainlify:

- To remove a single repository, edit your Grainlify GitHub App
  installation on GitHub and deselect it.
- To disconnect everything, uninstall the Grainlify GitHub App entirely from
  your GitHub account or organization's settings.

Either way, Grainlify picks up the change automatically and takes the
project down from Discover and Browse. Reinstalling or re-adding the
repository brings it right back.
